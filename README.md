# 💫 About Me
Hi, I'm Soufiane Tajri! I am a Software Engineer and Game Developer based in Morocco. 

My academic background bridges structured software engineering and interactive design. I hold a degree in Information Systems Development and am currently completing my Moroccan state Master's level (DENSAD) degree in Game Design & Animation at ENSAD. 

I am deeply passionate about engineering high-performance software architectures, backend systems, and interactive gameplay mechanics. Whether I am architecting end-to-end solo game projects with complex finite state machines, exploring low-level C++ engine internals, or developing full-stack web applications, I love building systems that are technically robust and engaging to interact with.
